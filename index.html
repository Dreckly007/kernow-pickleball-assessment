This assessment scores 11 skills, each rated 1–10:

  1. Serve
  2. Return
  3. Groundstrokes
  4. Third Shot
  5. Dinking
  6. Volleys
  7. Attacking
  8. Defence
  9. Movement
  10. Strategy
  11. Match Reliability

Tap the "?" next to any skill for what each score band actually looks like, from Developing through to Advanced.

Scores are combined using a weighting profile that depends on the assessment type you choose (Club Rating, Coach, Self, Match Observation or Training/Drill), producing an estimated DUPR rating and a Kernow Pickleball Club rating band.

This is a field-testing version for coaching and club guidance — the DUPR figure is an estimate, not an official DUPR rating.

  1. Enter the player's name, the assessment date, and any coach notes.
  2. Choose the assessment type first — it changes how heavily each skill is weighted in the final rating, so picking it later can shift the result.
  3. Score each of the 11 skills from 1 to 10, using the "?" tooltip on each skill if you're unsure which score fits.
  4. Press Analyze to see the estimated DUPR rating, club rating, strengths and priority focus area.
  5. Use Share PDF Report to export or print the result, or Reset Form to start the next player.

Two hidden extras: the button just before “Kernow” in the title reveals a weighting comparison table across all assessment types; the button just after the title reveals five sample players you can load to try the tool before using it for real.
